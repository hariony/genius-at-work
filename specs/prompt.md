25. AUTOMATISATION DATABASE
==================================================

IMPORTANT.

Lors du déploiement sur un environnement neuf, la CI/CD doit pouvoir :

1. démarrer les services nécessaires
2. vérifier MySQL
3. créer la base si elle n'existe pas
4. exécuter les migrations
5. éventuellement charger les fixtures de démonstration uniquement en environnement de développement
6. vider/réchauffer le cache
7. vérifier l'état de l'application

Utiliser les commandes Symfony/Doctrine correctement.

Exemple logique :

php bin/console doctrine:database:create --if-not-exists
php bin/console doctrine:migrations:migrate --no-interaction

Ne jamais supprimer automatiquement une base de production.

La pipeline de production doit être SAFE.
